# Linux distributions

## What RHEL actually is
**RHEL** stands for Red Hat Enterprise Linux and its a commercial Linux distro built for servers and production environments. Companies pay for it because of the support, stability, and long release lifecycles. The code is open source.

## Where it fits vs other distros 
- **Fedora** → upstream, bleeding edge, community-driven. This is where new features get tested first.
- **CentOS Stream** → sits between Fedora and RHEL now, a rolling preview of what's coming in RHEL.
- **RHEL** → the stable, supported, "don't touch it for a decade" version companies run in production.

So the flow is roughly: Fedora → CentOS Stream → RHEL.

## Subscriptions
RHEL itself is free to download the subscription is really for official support, security patches, and certification of hardware/software.That's why "free RHEL" and "paid RHEL" can both exist and aren't contradictory.

## Why enterprises care
- Predictable release cycles = less breakage.
- Long-term support = don't have to re-certify apps constantly.
- Red Hat certifications (RHCSA, RHCE) are recognized industry-wide, which is part of why this course exists.
