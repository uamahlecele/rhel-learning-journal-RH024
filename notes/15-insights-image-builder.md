# Insights Image Builder

## What is Image Builder
Image Builder is a Red Hat Insights tool for creating custom, ready-to-deploy RHEL images — instead of installing RHEL manually and configuring it afterward, you define what you want and it builds the image directly.

## Highlights
- Connects directly to Image Mode — Image Builder is essentially how the custom images that Bootc later deploys and manages actually get produced.
- Useful for consistency at scale: build one image with everything baked in, deploy it everywhere, instead of manually configuring many servers identically and risking drift over time.
- Part of the broader Insights suite, which leans toward fleet-level management rather than single-system administration.

## Terms I had to look up
- **Image Builder** — a Red Hat tool for creating customized OS images with specific packages, configs, and users pre-baked in, rather than configuring a system manually after install.
- **Red Hat Insights** — the broader platform for proactive management and monitoring across a fleet of RHEL systems.
