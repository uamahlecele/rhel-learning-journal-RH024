# Introduction to the Shell

## What is the Shell
The shell is the outermost layer of the operating system. Shells incorporate a programming language to control processes and files, as well as to start and control other programs. On RHEL the default is **bash** (stands for Bourne Again Shell) This is where most admin work happens.
 

## Highlights
- Tab completion saves so much typing and avoids typos in paths.
- The shell is case-sensitive. `File.txt` and `file.txt` are two different files.
- Up/down arrows scroll through command history instead of retyping.
- `Ctrl+C` kills whatever's running; `Ctrl+D` or `exit` logs you out of the shell.

## Terms I had to look up
- **Shell** — the command interpreter itself (bash, zsh, etc.), not the terminal window. Terminal = the app; shell = the program running inside it.
