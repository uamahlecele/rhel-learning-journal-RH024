# Editing Files with Vim
 
## What is Vim
Vim is a text editor that's installed on nearly every Linux server by default, which makes it worth being at least functional in — it's the one editor guaranteed to be there when SSH'd into a box with nothing else configured.
 
## Highlights
- Vim has modes — normal mode for navigation/commands, insert mode for actually typing. This was the biggest "oh, that's why it felt broken" moment.
- `i` enters insert mode, `Esc` exits back to normal mode, `:wq` saves and quits, `:q!` quits without saving.
- Getting stuck in Vim the first time is basically a rite of passage.
## Terms I had to look up
- **Normal mode vs Insert mode** — normal mode is for navigation and commands, insert mode is for typing text; mixing them up is the most common source of confusion for beginners.
